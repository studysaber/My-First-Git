## 发生回归时

停止分享新链接，保留故障截图与 Actions 日志。优先用一个新的 `git revert <发布提交>` 提交恢复先前版本，再让 Actions 重新验收与部署；不要改写仓库历史，也不要清理访问者浏览器的本地学习记录。新版会同步自评到旧版 v1 键；若回退期旧版继续修改自评，再升级时新版会以该 v1 改动为准。旧版不能读取 v2 练习记录，发布前导出的 JSON 仍应保留供再次升级后恢复。
