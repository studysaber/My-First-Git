# GitHub Pages 发布与回退清单

目标仓库：`studysaber/My-First-Git`；目标地址：`https://studysaber.github.io/My-First-Git/`。只发布 `dist/`，不发布测试、计划或本地备份。

## 发布前

- [ ] `npm ci` 成功；`npm test` 与 `npm run test:browser` 全部通过。
- [ ] 以 1440×1000、1024×768、390×844、320×720 检查正文；以桌面/手机检查实验和章节总览；没有整页横向溢出与遮挡。
- [ ] 单摆、驻波、麦克斯韦分布、卡诺循环、双缝、光电效应和相对论的数值趋势与读数一致；无越界参数出现 `NaN` 或无根据的动效。
- [ ] 先导出当前浏览器学习记录，再验证 v2 备份能恢复自评与练习；旧 v1 文件只改自评，未知版本和陌生 ID 被拒绝。
- [ ] `git diff --check` 通过；KaTeX 版本固定，字体和 `LICENSE` 在 `dist/assets/vendor/katex/`；页面没有运行时 CDN 依赖。
- [ ] 仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**；不要同时依赖原 `/docs` 分支发布。

## 发布后

- [ ] 记录发布提交：`待填写`。
- [ ] 记录 Actions 验收及部署运行链接：`待填写`。
- [ ] 记录 Settings → Pages 的来源与访问 URL：`待填写`。
- [ ] 打开带前缀路径的首页、直接知识点链接和刷新后的练习页；核对 CSS、KaTeX 字体、SVG、脚本均未返回 404。
- [ ] 在目标使用地区与网络实测访问。GitHub Pages 的公开可访问性不等于所有中国大陆网络均可稳定访问。
- [ ] 用干净浏览器走完搜索、章节筛选、实验预测/参数变化、作答、下载备份、导入备份和浏览器后退。

## 发生回归时

停止分享新链接，保留故障截图与 Actions 日志。优先用一个新的 `git revert <发布提交>` 提交恢复先前版本，再让 Actions 重新验收与部署；不要改写仓库历史，也不要清理访问者浏览器的本地学习记录。旧版页面可能不识别 v2 练习记录，发布前导出的 JSON 应保留供再次升级后恢复。
