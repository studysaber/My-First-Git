# Reading workspace

Mode: Read, with Operate controls for scientific experiments and self-testing. Students use this during daytime desk study; a light reading surface lowers visual competition with the scientific content.

## Direction contract

THESIS: A physics handbook that moves directly from a named concept to observation and self-testing; refuse the discarded dark dashboard and oversized route diagram.

OWN-WORLD: Warm white page, white reading area, charcoal Chinese system type, forest-green selection and primary actions. Thin neutral rules and generous continuous space replace nested cards and glow.

STORY: Find a chapter, understand one concept, change a physical parameter, then test recall. Keep historical evidence and current review needs distinct.

FIRST VIEWPORT: Slim brand/search/review header, quiet roughly 240px chapter directory, broad reading pane with one heading, summary and four task tabs. On experiment, the model occupies the left of one airy area and controls/readout the right; start-practice sits at the reading footer. Mobile places a closed directory disclosure before the current concept.

FORM: User-pinned first image, shallow learning-handbook navigation, replacing the incumbent template. Seed 7886ee29 recorded; the user-pinned composition and palette win the assignment. Scientific geometry and factual text are corrected rather than copied from generated pixels.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Approved reference and constraints

docs/design-reference/handbook-preview.png is the selected first image. No screenshot or generated plate is used as a physics diagram; every plot is a runtime data chart. Preserve routes, learning records, backups, local KaTeX and original GitHub Pages publication. Additional controls required by actual model/content inherit the same quiet hierarchy. No marketing hero, decorative backgrounds, login or remote runtime fonts.
